# Contributing

MoheetBrain maintains this independent research repository. Fork it to study,
reproduce or modify your own copy. Propose changes through a pull request with
its scientific rationale and appropriate verification. Only the maintainer may
merge changes to the original repository. Do not submit confidential data,
credentials, restricted catalogues or results you lack authority to publish.

Retain source attribution and licence notices. Mark scientific changes and new
experiments distinctly; do not silently overwrite the archived findings.
